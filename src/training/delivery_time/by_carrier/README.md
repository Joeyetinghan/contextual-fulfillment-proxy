# Carrier-Specific Delivery Time Model Training

This directory contains training scripts for carrier-specific delivery time models. Each script trains separate models for each of the 18 carrier services.

## Available Training Scripts

### 1. `train_quantile_models.py` ✅ (Ready)
Trains XGBoost quantile regression models per carrier service.

**Usage:**
```bash
python -m src.training.delivery_time.by_carrier.train_quantile_models [--train_on_proxy]
```

**Output:**
- Models: `data/models/delivery_time_cs/delivery_model_{carrier_id}.joblib`
- Plots: `data/plots/delivery_time_cs/loss_curve_carrier_{carrier_id}.png`

### 2. `train_dl_rf.py` ✅ (Ready)
Trains Deep Learning (PyTorch) and/or Random Forest Quantile models per carrier.

**Usage:**
```bash
# Train DL models only
python -m src.training.delivery_time.by_carrier.train_dl_rf --use_dl [--train_on_proxy]

# Train RF models only
python -m src.training.delivery_time.by_carrier.train_dl_rf --use_qrf [--train_on_proxy]

# Train both
python -m src.training.delivery_time.by_carrier.train_dl_rf --use_dl --use_qrf [--train_on_proxy]
```

**Output:**
- DL Models: `data/models/delivery_time_cs/tune/dl_model_{carrier_id}.pt`
- RF Models: `data/models/delivery_time_cs/tune/rf_model_{carrier_id}.joblib`
- Plots: `data/plots/delivery_time_cs/loss_curve_dl_carrier_{carrier_id}.png`

### 3. `train_simulator.py` ✅ (Ready)
Trains CatBoost classifier simulators per carrier for discrete-event simulation.

**Usage:**
```bash
# Basic training
python -m src.training.delivery_time.by_carrier.train_simulator

# With hyperparameter tuning
python -m src.training.delivery_time.by_carrier.train_simulator --n_trials 20

# Choose the simulator type (catboost or dl)
python -m src.training.delivery_time.by_carrier.train_simulator --simulator_type catboost
```

**Output:**
- Models: `data/models/delivery_time_cs/simulator_{simulator_type}_{carrier_id}.joblib` (e.g. `simulator_dl_1.joblib`, `simulator_catboost_1.joblib`)
- Plots: `data/plots/delivery_time_cs/simulator/dist_comparison_carrier_{carrier_id}.png`

## Data Requirements

All carrier-specific training scripts require:
- **Input:** `data/processed/preprocessed_data_cs.csv` (generated by `python -m src.data_augmentation.sample_carrier_services`)
- **Key Column:** `carrier_service_id_anon` - identifies which carrier service handled each delivery

## Common Utilities

All scripts use shared functions from `src/training/delivery_time/common.py`:
- Data loading and splitting
- Feature engineering (order-level, time, DC features)
- Categorical encoding
- Plotting functions
- Loss computation

## Model Selection Guide

### XGBoost (`train_quantile_models.py`) - **Recommended for most use cases**
**Best for:** Production deployment, fast training, general-purpose prediction
- ✅ Fast to train (~minutes per carrier)
- ✅ Good performance on delivery time prediction
- ✅ Handles all quantiles
- ✅ Lower memory footprint
- ✅ Easier to deploy

### Deep Learning (`train_dl_rf.py --use_dl`) - **For maximum accuracy**
**Best for:** When you need the absolute best predictions and have GPU resources
- ✅ Often achieves best performance
- ⚠️ Slower to train (requires GPU for reasonable speed)
- ⚠️ Larger model size
- ⚠️ Requires PyTorch in deployment

### Random Forest (`train_dl_rf.py --use_qrf`) - **Alternative to XGBoost**
**Best for:** Non-parametric approach, feature importance analysis
- ✅ No hyperparameter tuning needed
- ✅ Naturally handles outliers
- ⚠️ Larger model size than XGBoost
- ⚠️ Slower inference

### Simulator (`train_simulator.py`) - **For discrete-event simulation**
**Best for:** When you need to simulate the stochastic delivery process
- ✅ Trained on test set (approximates true distribution)
- ✅ Outputs probability distributions
- ✅ Useful for Monte Carlo simulation
- ⚠️ Classification-based (discretizes delivery times)
