# Delivery Time Model Training

This directory contains delivery-time forecasting models. The public paper workflow uses carrier-specific models.

## Carrier-Specific Models

```bash
python -m src.training.delivery_time.by_carrier.train_dl_rf --use_dl
```

Additional carrier-specific baselines:

```bash
python -m src.training.delivery_time.by_carrier.train_quantile_models --model_type xgboost
python -m src.training.delivery_time.by_carrier.train_quantile_models --model_type sklearn
python -m src.training.delivery_time.by_carrier.train_simulator
```

Carrier-specific models use `data/processed/preprocessed_data_cs.csv`, generated by:

```bash
python -m src.data_augmentation.sample_carrier_services
```

Outputs are written under `data/models/delivery_time_cs/` and `data/plots/delivery_time_cs/`.

## Global Baselines

Global carrier-agnostic baselines remain available for comparison:

```bash
python -m src.training.delivery_time.global.train_dl_rf --use_dl
python -m src.training.delivery_time.global.train_dl_rf --use_qrf
python -m src.training.delivery_time.global.train_quantile_models --model_type xgboost
python -m src.training.delivery_time.global.train_simulator
```

Global outputs are written under `data/models/delivery_time/` and `data/plots/delivery_time/`.

## Shared Utilities

`common.py` provides data loading, categorical encoding, feature helpers, plotting, and pinball-loss helpers shared by the delivery-time training entrypoints.
